## Installation manuelle

1. Installe **Tampermonkey** ([Chrome](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) / [Firefox](https://addons.mozilla.org/fr/firefox/addon/tampermonkey/)).
2. Ouvre Tampermonkey et clique sur **Créer un nouveau script**.
3. Copie le contenu de [`VELTRIXJS.user.js`](https://github.com/VeltrixJS/Cheat-Narrow-One/blob/main/VELTRIXJS.user.js).
4. Colle le code dans l'éditeur et sauvegarde avec `Ctrl + S`.
5. Ouvre [Narrow One](https://narrow.one/) et vérifie que le script est activé.

## Utilisation

- **`Insert`** — Ouvrir / fermer le menu
- **`F`** — Toggle Aimbot
- **`E`** — Toggle ESP
- **`X`** — NoClip (maintenir)
- **`T`** — Chat
- **Clic droit** — Aimbot (maintenir)

Toutes les options sont configurables depuis le menu.

---

## Fonctionnalités

**Combat** — Speed, Jump, Fly, NoClip, Bunny Hop, Zoom, God Mode, Wallbang, Fast Fire

**Aimbot** — Ciblage personnalisable, zones de visée, lissage, humanisation, FOV

**Triggerbot** — Détection automatique, Line of Sight, portée configurable

**ESP** — Boxes, distances, pseudos, vie, ping, armes, tracers, radar, liste des joueurs

**Visuel** — Sky mod, X-Ray, crosshair personnalisé, HUD

**Drapeau** — Alerte de capture, texture personnalisée
